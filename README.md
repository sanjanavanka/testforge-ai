# testforge-ai

## 🚀 v2.0.0 — Market-Ready Edition: LLM Brain + OEM Translator + Defect Predictor + Jira Exporter

- **🧠 Local LLM Brain** — Fully offline AI chat assistant using rule-based pattern matching + STATE context. Floating bubble (bottom-left) + full-page chat view. Answers questions about requirements, tests, edge cases, and best practices. Persistent history, typing animation, quick-prompt chips.
- **🌐 Multi-OEM Translator** — Translates requirements between 7 OEM terminologies (BMW, Mercedes, VW, Stellantis, Ford, GM, Toyota). Side-by-side preview, glossary changes table, bulk translate, custom term editor.
- **🔮 AI Defect Predictor** — Heuristic risk scoring (0–100) for every requirement based on quality score, complexity, timing, vague words, change frequency, and test failures. Risk heat map, prioritized recommendations, exportable risk report.
- **🎫 Jira Story Exporter** — Generates Jira-formatted stories with auto-estimated story points, acceptance criteria, linked tests, and bulk CSV export. Per-requirement and bulk export on Requirements + Reports views.
- **💰 ROI Dashboard** — Calculates and displays engineer-hours saved, working days, and dollar value based on actual project metrics. Exportable ROI report.
